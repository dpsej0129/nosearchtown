# 권외 — 검색되지 않는 마을

가상 데스크톱에서 진행하는 ARG풍 검색·SNS 추리 어드벤처. 플레이 시간 약 2~3시간.

2009년 오봉, 인기 생방송 주 「유메링」이 지도에서 사라진 마을 히나고에서 방송 도중 사라졌다.
익명 게시판의 특정반은 사흘 만에 마을 입구의 민박 주인을 「범인」으로 지목했다.
2026년 11월, 그 특정반의 핵심 멤버였던 당신의 낡은 노트북에 메일이 온다. — 「특정, 아직 안 끝났어.」

## 플레이

**`index.html` 하나만 브라우저로 열면 됩니다.** 외부 라이브러리·이미지·서버가 필요 없습니다.
PC 브라우저를 권장하며, 모바일 브라우저에서는 창이 전체 화면 탭으로 바뀝니다.
진행은 브라우저(localStorage)에 자동 저장됩니다.

- 검색창에는 **한 단어만** 들어갑니다. 인물 이름은 붙여 쓰세요.
- 개발자 도구나 소스를 볼 필요가 없는 게임입니다. 정답과 검색어는 소스에 해시값으로만 들어 있습니다.
- 실종, 스토킹, 인터넷 여론 폭력을 다룹니다(살인·고어 묘사 없음). 모든 인물·단체·사이트·마을은 가상입니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 완성된 단일 파일 게임 (① HTML/CSS → ② 엔진 JS → ③ GAME_DATA 순서) |
| `CHECKLIST.md` | 완성 후 점검표 — **전체 스포일러** |
| `src/template.html`, `src/style.css` | 화면 골격과 스타일 |
| `src/engine.js`, `src/hash.js` | 엔진 (창 관리, 13개 앱, 진행·저장·효과음) / 정규화·해시·잠금 해제 |
| `src/data/*.js` | 시나리오 데이터: 공통(인물·엔딩), 서장~종장, SVG 장면 — **스포일러, 정답 평문 포함** |
| `tools/build.js` | 빌드: 정답·검색어 해시화, 보호 글 암호화, 참조 검사, 일본어 문자 검사 |
| `tools/playtest.js` | 처음부터 진엔딩까지 실제 UI로 진행하는 자동 테스트 (Playwright) |

## 빌드 · 테스트

```bash
node tools/build.js --stats
```

```bash
node tools/playtest.js
```

`src/`를 고친 뒤에는 빌드를 다시 돌려 `index.html`을 만들어야 합니다. 빌드는 데이터 참조 오류나 가나·한자가 하나라도 있으면 실패합니다.
